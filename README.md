# Sales Trend Analysis Using SQL

## Overview
This project analyzes an e-commerce sales dataset using SQL to identify monthly revenue trends, order volume, and overall sales performance.

## Tools Used
1) MySQL
2) GitHub
3) Kaggle Dataset

## Tasks Performed
1) Calculated monthly revenue using SUM()
2) Analyzed monthly order volume using COUNT(DISTINCT order_id)
3) Grouped data by month and year
4) Identified top 3 months by sales
5) Performed time-based sales analysis
6) Analyzed revenue by category and return status

## Conclusion
This project demonstrates how SQL can be used to analyze sales data and extract meaningful business insights through aggregation, filtering, and trend analysis.
